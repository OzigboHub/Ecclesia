## Lumina Digital Parish Manager (DPM)

**Version:** 1.0  
**Last Updated:** January 2026  
**Module:** Mass Scheduling & Intentions

## 1. Overview

This document specifies the automated Mass scheduling system and its integration with Mass Intentions. The system automatically creates daily Masses based on parish schedules, enforces intention booking rules, and ensures intentions are tied to valid Masses.

### 1.1 Key Requirements

1. ✅ **Automatic Mass Creation**: Daily Masses are created automatically based on parish schedule templates
2. ✅ **Adjustable Times**: Mass times can be adjusted or cancelled by authorized users
3. ✅ **Mass Limit**: Maximum 5 Masses per day per organization
4. ✅ **Minimum Requirement**: At least 1 Mass per day (typically)
5. ✅ **Intention Dependency**: Mass intentions can ONLY be booked for existing Masses
6. ✅ **No Mass = No Intention**: If no Mass scheduled, intention booking is blocked
7. ✅ **Auto-scheduling**: Masses scheduled 90 days in advance

## 4. Automatic Mass Generation

### 4.1 Generation Logic

The system runs a **daily cron job** that:
1. Checks all active Mass schedule templates
2. Generates individual Mass events for the next 90 days
3. Skips dates that already have generated Masses
4. Respects the `maxMassesPerDay` limit per organization

### 4.2 Generation Algorithm

```typescript
// lib/cron/generateMasses.ts

async function generateMasses() {
  const organizations = await prisma.organization.findMany({
    where: { autoGenerateMasses: true },
    include: { massScheduleTemplates: true }
  });

  for (const org of organizations) {
    const startDate = new Date();
    const endDate = addDays(startDate, org.generateDaysInAdvance);

    // Loop through each day
    for (let date = startDate; date <= endDate; date = addDays(date, 1)) {
      const dayOfWeek = getDayOfWeek(date); // "MONDAY", "TUESDAY", etc.
      
      // Get templates for this day
      const templates = org.massScheduleTemplates.filter(
        t => t.dayOfWeek === dayOfWeek && t.isActive
      );

      // Check if Masses already exist for this date
      const existingMasses = await prisma.mass.findMany({
        where: {
          organizationId: org.id,
          date: {
            gte: startOfDay(date),
            lte: endOfDay(date)
          }
        }
      });

      // Calculate how many more Masses we can create
      const remainingSlots = org.maxMassesPerDay - existingMasses.length;
      
      if (remainingSlots <= 0) continue; // Max reached for this day

      // Generate Masses from templates (up to remaining slots)
      for (const template of templates.slice(0, remainingSlots)) {
        // Check if Mass at this exact time already exists
        const duplicate = existingMasses.find(
          m => m.time === template.time
        );
        
        if (duplicate) continue; // Skip duplicate

        // Create the Mass
        await prisma.mass.create({
          data: {
            organizationId: org.id,
            date: date,
            time: template.time,
            massType: template.massType,
            language: template.language,
            location: template.location,
            status: 'SCHEDULED',
            isAutoGenerated: true,
            templateId: template.id,
            maxIntentions: 1, // Default: 1 intention per Mass
            bookedIntentions: 0
          }
        });

        // Log creation
        await prisma.auditLog.create({
          data: {
            action: 'CREATE',
            entityType: 'Mass',
            entityId: mass.id,
            performedBy: 'SYSTEM',
            details: {
              auto_generated: true,
              template_id: template.id,
              date: date.toISOString()
            }
          }
        });
      }
    }
  }
}

// Run daily at 2:00 AM
cron.schedule('0 2 * * *', generateMasses);
```

## 6. Mass Intention Booking Rules

### 6.1 Validation Rules

**Rule 1: Mass Must Exist**
```typescript
async function validateMassExists(massId: string, organizationId: string) {
  const mass = await prisma.mass.findFirst({
    where: {
      id: massId,
      organizationId: organizationId,
      status: { in: ['SCHEDULED', 'IN_PROGRESS'] }
    }
  });

  if (!mass) {
    throw new Error('Invalid Mass selected. Mass does not exist or has been cancelled.');
  }

  return mass;
}
```

**Rule 2: Mass Date Must Be Future**
```typescript
function validateMassDate(mass: Mass) {
  const massDateTime = new Date(`${mass.date}T${mass.time}`);
  
  if (massDateTime <= new Date()) {
    throw new Error('Cannot book intention for past Masses');
  }
}
```

**Rule 3: Check Mass Capacity**
```typescript
function validateMassCapacity(mass: Mass) {
  if (mass.bookedIntentions >= mass.maxIntentions) {
    throw new Error(`This Mass is fully booked. Maximum ${mass.maxIntentions} intention(s) allowed.`);
  }
}
```

**Rule 4: Check Organization Match**
```typescript
function validateOrganization(mass: Mass, intentionOrgId: string) {
  if (mass.organizationId !== intentionOrgId) {
    throw new Error('Cannot book intention for Mass in different organization');
  }
}
```

### 6.2 Booking Flow

```typescript
// POST /api/mass-intentions

async function bookMassIntention(data: MassIntentionInput) {
  // 1. Validate Mass exists and is bookable
  const mass = await validateMassExists(data.massId, data.organizationId);
  
  // 2. Validate Mass date
  validateMassDate(mass);
  
  // 3. Check capacity
  validateMassCapacity(mass);
  
  // 4. Check organization
  validateOrganization(mass, data.organizationId);
  
  // 5. Create intention
  const intention = await prisma.massIntention.create({
    data: {
      intention: data.intention,
      intentionType: data.intentionType,
      requestedBy: data.requestedBy,
      contactEmail: data.contactEmail,
      contactPhone: data.contactPhone,
      massId: data.massId,
      parishionerId: data.parishionerId,
      organizationId: data.organizationId,
      stipend: data.stipend,
      status: 'PENDING' // Requires approval
    }
  });
  
  // 6. Send confirmation email
  await sendEmail({
    to: data.contactEmail,
    subject: 'Mass Intention Booking Received',
    template: 'intention-confirmation',
    data: {
      intention,
      mass,
      pendingApproval: true
    }
  });
  
  return intention;
}
```

### 6.3 Approval Flow

```typescript
// PUT /api/mass-intentions/:id/approve

async function approveMassIntention(intentionId: string, userId: string) {
  // Get intention
  const intention = await prisma.massIntention.findUnique({
    where: { id: intentionId },
    include: { mass: true }
  });

  if (!intention) {
    throw new Error('Intention not found');
  }

  // Check Mass capacity again (race condition protection)
  const mass = intention.mass;
  if (mass.bookedIntentions >= mass.maxIntentions) {
    throw new Error('Mass is now fully booked');
  }

  // Use transaction to ensure atomicity
  await prisma.$transaction([
    // Update intention status
    prisma.massIntention.update({
      where: { id: intentionId },
      data: {
        status: 'APPROVED',
        approvedBy: userId,
        approvedAt: new Date()
      }
    }),
    
    // Increment booked count
    prisma.mass.update({
      where: { id: mass.id },
      data: { bookedIntentions: { increment: 1 } }
    }),
    
    // Audit log
    prisma.auditLog.create({
      data: {
        action: 'UPDATE',
        entityType: 'MassIntention',
        entityId: intentionId,
        performedBy: userId,
        details: {
          status_change: 'PENDING -> APPROVED',
          mass_date: mass.date,
          mass_time: mass.time
        }
      }
    })
  ]);

  // Send approval email
  await sendEmail({
    to: intention.contactEmail,
    subject: 'Mass Intention Approved',
    template: 'intention-approved',
    data: { intention, mass }
  });
}
```

## 9. Business Rules Summary

### 9.1 Mass Creation Rules

1. ✅ Maximum 5 Masses per day per organization (configurable)
2. ✅ Minimum 1 Mass per day (typically, configurable)
3. ✅ Auto-generated 90 days in advance
4. ✅ No duplicate Masses at same date/time
5. ✅ Templates can be active/inactive
6. ✅ Manual Masses can override auto-generation

### 9.2 Mass Intention Rules

1. ✅ **MUST be tied to a valid Mass** - Cannot book without Mass
2. ✅ Mass must be in the future
3. ✅ Mass must not be cancelled
4. ✅ Mass must have available capacity
5. ✅ Must belong to same organization as Mass
6. ✅ Requires approval before confirmation
7. ✅ When Mass cancelled, intentions reset to pending

### 9.3 Capacity Rules

1. ✅ Each Mass has `maxIntentions` (default: 1)
2. ✅ Parish can configure higher limits (e.g., 3 intentions per Mass)
3. ✅ `bookedIntentions` cannot exceed `maxIntentions`
4. ✅ Atomic increment to prevent race conditions

   - Configure languages and locations

2. **Generate Initial Masses**

   - Link old intentions to new Mass records
   - Update statuses accordingly

4. **Train Staff**
   - Mass schedule management
   - Intention approval process
   - Handling cancellations

### 12.2 Database Migration Script

```typescript
// prisma/migrations/xxx_add_mass_system.ts

import { PrismaClient } from '@prisma/client';

async function migrate() {
  const prisma = new PrismaClient();

  // 1. Add new columns to Organization
  await prisma.$executeRaw`
    ALTER TABLE "Organization"
    ADD COLUMN "maxMassesPerDay" INTEGER DEFAULT 5,
    ADD COLUMN "minMassesPerDay" INTEGER DEFAULT 1,
    ADD COLUMN "autoGenerateMasses" BOOLEAN DEFAULT true,
    ADD COLUMN "generateDaysInAdvance" INTEGER DEFAULT 90;
  `;

  // 2. Create new tables
  // (Handled by Prisma schema migration)

  // 3. For each organization, create default templates
  const organizations = await prisma.organization.findMany();

  for (const org of organizations) {
    // Create basic weekday Mass template
    await prisma.massScheduleTemplate.create({
      data: {
        organizationId: org.id,
        dayOfWeek: 'MONDAY',
        time: '06:00',
        massType: 'DAILY_MASS',
        language: 'English',
        isActive: true
      }
    });

    // Create Sunday Mass templates
    for (const time of ['06:00', '08:00', '10:00']) {
      await prisma.massScheduleTemplate.create({
        data: {
          organizationId: org.id,
          dayOfWeek: 'SUNDAY',
          time: time,
          massType: 'SUNDAY_MASS',
          language: 'English',
          isActive: true
        }
      });
    }
  }

  console.log('Migration completed successfully');
}

migrate();
```
