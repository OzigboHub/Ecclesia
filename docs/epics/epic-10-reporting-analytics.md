This epic covers the reporting and analytics capabilities across the system, including financial reports, membership statistics, sacramental records, and dashboard analytics. Reports support data-driven decision making for parish leadership.

## Technical Notes

### Report Types

-   **Dashboard**: Real-time widgets
-   **On-Demand**: Generated when requested
-   **Scheduled**: Auto-generated on schedule
-   **Standard**: Pre-defined formats (diocesan registers)
-   **Custom**: User-configured parameters

### Export Formats

-   PDF (for printing, official documents)
-   Excel/XLSX (for analysis)
-   CSV (for data interchange)

### Feature Toggle Integration

-   Basic reporting always available
-   Advanced analytics may require feature toggle
-   Financial reports depend on `enableFinancialManagement`

### Performance Considerations

-   Large reports should be generated asynchronously
-   Cache frequently accessed dashboard data
-   Index database columns used in report filters
-   Consider date partitioning for historical data

### Database Schema Additions

```prisma
model SavedReport {
  id              String       @id @default(uuid())
  name            String
  reportType      String       // e.g., "payment", "parishioner"
  parameters      Json         // Saved filter parameters

  createdById     String
  createdBy       User         @relation(...)

  organizationId  String
  organization    Organization @relation(...)

  createdAt       DateTime     @default(now())
  updatedAt       DateTime     @updatedAt
}

model ReportSchedule {
  id              String        @id @default(uuid())
  reportType      String
  parameters      Json
  schedule        String        // CRON expression
  format          ReportFormat
  recipients      String[]      // Email addresses
  isActive        Boolean       @default(true)
  lastRunAt       DateTime?

  createdById     String
  createdBy       User          @relation(...)

  organizationId  String
  organization    Organization  @relation(...)

  createdAt       DateTime      @default(now())
  updatedAt       DateTime      @updatedAt
}

model ReportHistory {
  id              String       @id @default(uuid())
  reportType      String
  parameters      Json
  format          ReportFormat
  fileUrl         String?      // Stored report file
  status          ReportStatus
  errorMessage    String?

  generatedById   String
  generatedBy     User         @relation(...)

  organizationId  String
  organization    Organization @relation(...)

  createdAt       DateTime     @default(now())
}

enum ReportFormat {
  PDF
  XLSX
  CSV
}

enum ReportStatus {
  PENDING
  GENERATING
  COMPLETED
  FAILED
}
```
